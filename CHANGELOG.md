# Changelog

All notable changes to `spatie-simple-excel` will be documented in this file.

## 1.0.0 - 2026-11-24

- Initial Rust port with CSV, XLSX and ODS reading and writing, header and value transformations, multiple sheets, styles, formulas and download sinks.
- Streaming CSV and constant-memory XLSX exports, with explicit documentation of spreadsheet reading and ODS memory costs.
